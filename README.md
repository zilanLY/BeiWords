# BeiWords 背单词Lite

复刻「不背单词」(bbdc.cn) 学习逻辑的 Android 背单词应用，**新增了导入生词功能**。

> 本项目基于对不背单词 v5.11.7 官方 APK 的静态逆向分析（分析报告见 [docs/bbdc-analysis.md](docs/bbdc-analysis.md)），
> 用 Kotlin + Jetpack Compose 独立重新实现其学习/复习算法，未使用任何原版代码或资源，仅供个人学习研究。

## 核心功能

### 1. 原版背诵逻辑复刻

| 原版机制（逆向确认） | 本项目实现 |
|---|---|
| 莱特纳记忆盒调度（`coreengine/LeitnerCardInMemoryImp`） | `SrsEngine`：L0~L6 级间隔 20分钟 → 12小时 → 1天 → 2天 → 4天 → 7天 → 15天 → 毕业不再安排 |
| 三级自评「认识 / 模糊 / 忘记了」（`doKnownProcess`/`doUnKnownProcess`/`iDontKnow`） | 新词首现与复习回忆卡均采用三档自评 |
| 连续答对闯关（“连续答对 N 次完成本词学习”“答对次数已清零”） | `REQUIRED_CONSECUTIVE=3`，答错连对清零并**当场重现**（错词重现） |
| 最后一关无提示拼写（“本词最后一关：请在无提示的情况下判断”） | 新词卡片流末尾为无提示拼写关 |
| 词进度小圆点（`getWordMaxLevel`/`ProgressLevelView`） | 卡片顶部等级圆点 |
| “通过多轮复习达到掌握标准后，系统自动判断单词为复习完成” | 满级 L7 自动毕业 |
| 组学习（“%d 词/组”）、学习节奏、复习节奏 | 4 词/组切组穿插，每日新词配额 5~50 可调，复习到期自动混排 |
| “本词学习完成，已进入复习队列” | 闯关完成 → `stage=复习中`，按阶梯到期 |
| “辨识后拼写，更能加强记忆哦” | 复习自评模糊/忘记 → 自动追加拼写卡 |

### 2. 导入生词功能（新增）

- **文件导入**：选择 `.txt` / `.csv` 文件（系统文件选择器）
- **粘贴导入**：直接粘贴文本
- 每行格式：`单词<Tab>释义`、`单词,释义`、`单词 释义`、`单词:释义`、`单词=释义`、`单词|释义|英文例句(可选)`
- 自动去重、跳过无效行、可命名词书
- 导入即生成自定义词书，与内置词书走**完全相同的背诵逻辑**

### 3. 其他

- 单词发音（系统 TTS，美音）
- 词书管理（切换/删除自定义词书）
- 学习统计（已学/已掌握/今日任务）
- 内置 CET-4 核心词示例词书 80 词

## 截图流程（文字版）

```
首页 ─┬─ 今日学习&复习（待复习 N / 待学新词 N / 闯关中 N）
      ├─ 学习节奏（每日新词 5~50）
      ├─ 词书管理 ── 切换/删除
      └─ 导入生词 ── 文件 / 粘贴 → 解析预览 → 生成词书

学习卡片流（一组4词）：
  新词首现(自评) → 词义四选一 → 例句选词 → 无提示拼写(最后一关)
  答错 → 连对清零 + 该卡追加到队尾重现
复习：回忆自评(认识/模糊/忘记了) → 模糊/忘记 追加拼写
```

## 构建

```bash
gradle assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

要求：JDK 17、Android SDK 34。GitHub Actions 已配置自动构建（`.github/workflows/build.yml`），
每次 push 自动编译并在 Release 发布 APK。
